## 1. التقنيات البرمجية المستخدمة (Tech Stack)
* **واجهة المستخدم:** React 18 مع TypeScript لتأمين الكود ومنع الأخطاء.
* **محرك البناء والتطوير:** Vite 6 لسرعة التجميع وبناء الحزم الخفيفة.
* **التصميم والتنسيق:** Tailwind CSS مع دعم كامل للكتابة والاتجاه العربي (`dir="rtl"`).
* **الأيقونات والتأثيرات:** Lucide React Icons و Canvas Confetti.
* **محرك البيانات السحابي:** Supabase JS Client v2 مع دعم Realtime.

## 3. كيفية تشغيل المشروع محلياً (Local Development)

إذا أردت تجربة أو تشغيل المشروع محلياً على جهازك:
1. افتح موجه الأوامر (PowerShell).
2. قم بتوجيه المسار إلى بيئة Node.js المتاحة:
   ```powershell
   $env:PATH = "C:\Users\ferry\AppData\Local\hermes\tools\node-26.7.0-win32-x64;" + $env:PATH
   cd "C:\Users\ferry\Desktop\qoder"
   ```
3. لتشغيل سيرفر التطوير المحلي:
   ```powershell
   npm run dev
   ```
   - سيفتح المشروع على الرابط: `http://localhost:5173`

## 4. خطوات نشر التحديثات إلى Vercel Production

عند إجراء أي تعديلات جديدة في الأكواد وترغب في نشرها مباشرة إلى الموقع الحي:

### الخطوة 1: بناء الحزمة الإنتاجية (Build)
```powershell
$nodeDir = "C:\Users\ferry\AppData\Local\hermes\tools\node-26.7.0-win32-x64"
$env:PATH = "$nodeDir;C:\Users\ferry\Desktop\qoder\node_modules\.bin;" + $env:PATH
cd "C:\Users\ferry\Desktop\qoder"
npm run build
```

### الخطوة 2: مزامنة الملفات المبنية إلى فولدر النشر
```powershell
$dst = "C:\Users\ferry\Desktop\rawdah_deployment_ready - Copy"
Copy-Item -Path "C:\Users\ferry\Desktop\qoder\src" -Destination $dst -Recurse -Force
Copy-Item -Path "C:\Users\ferry\Desktop\qoder\dist" -Destination $dst -Recurse -Force
```

### الخطوة 3: إرسال أمر النشر إلى Vercel
```powershell
cd "C:\Users\ferry\Desktop\rawdah_deployment_ready - Copy"
npx vercel deploy --prod --yes
```
* فور انتهاء الأمر، يظهر تنبيه `▲ Aliased https://rawdahdeploymentready.vercel.app` وتكون التحديثات متاحة للعالم أجمع في نفس اللحظة.
