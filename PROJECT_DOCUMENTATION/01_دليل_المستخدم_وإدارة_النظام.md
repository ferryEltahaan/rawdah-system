# 📖 01: دليل المستخدم وإدارة النظام — Rawdah Enterprise

نظام حجز وإدارة تصاريح الروضة الشريفة هو منظومة سحابية متكاملة مصممة لإدارة حجز وتوزيع تصاريح الزيارة للروضة الشريفة، إدارة طلبات العملاء والمعتمرين، تتبع السدادات البنكية الفورية عبر الرسائل النصية، والتحكم في فريق العمل والصلاحيات.

---

## 1. شاشة تسجيل الدخول (Login Screen)
* **الرابط:** متاح على الصفحة الرئيسية للتطبيق.
* **البيانات المطلوبة:**
  - **اسم المستخدم أو البريد الإلكتروني:** يقبل الاسم بالعربية أو بالإنجليزية (مثال: `admin` أو `farid` أو `فريد` أو `مريم`).
  - **كلمة المرور:** المشفرة سحابياً على السيرفر.
* **الأمان:**
  - يتم التحقق السحابي عبر دالة سيرفر مشفرة (`rpc_authenticate_user`) دون حفظ كلمات المرور في المتصفح.
  - في حال إيقاف الحساب من قبل الإدارة، يرفض النظام الدخول تلقائياً مع إشعار الموظف.

---

## 2. شاشات ووحدات المنظومة

### أ. لوحة المؤشرات (الرئيسية - Dashboard)
* **المحتوى:**
  - إحصائيات حية: إجمالي المبيعات اليومية، التصاريح المتاحة، الطلبات قيد التنفيذ، والطلبات غير المسددة.
  - رسم بياني لتوزيع التصاريح حسب الفترات الزمنية.
  - أزرار الوصول السريع لأهم الإجراءات (طلب جديد، إضافة تصاريح، تسجيل عميل).

### ب. إدارة الفترات ومخزون التصاريح (Permits Inventory)
* **الوظائف:**
  - عرض الفترات المجدولة لزيارة الروضة موزعة بالساعة والدقيقة (فترات 00، 20، 40 دقيقة).
  - **إضافة تصاريح جديدة:** إمكانية رفع صور التصاريح فردياً أو سحب وإفلات جماعي.
  - **تخزين الصور السحابي:** تُرفع صور التصاريح مباشرة إلى باكت التخزين السحابي (`permits` bucket) لتوفير ذاكرة المتصفح وسرعة التصفح.
  - **تخصيص التصريح:** ربط التصريح بطلب عميل محدد وطباعته أو إرساله عبر الواتساب.
  - **نقل وإعادة توزيع التصاريح:** إمكانية نقل مجموعة تصاريح من فترة زمنية إلى فترة أخرى بنقرة زر.
  - **حذف التصاريح:** إمكانية حذف التصريح الخاطئ أو منتهي الصلاحية مع حذف صورته من السحابة تلقائياً.

### ج. إدارة الطلبات والمبيعات (Sales Orders)
* **الوظائف:**
  - إنشاء طلب جديد مع تحديد العميل، عدد التصاريح (رجال / نساء)، التاريخ المستهدف، والفترة المفضلة.
  - حساب إجمالي المبلغ، المبلغ المدفوع، والمتبقي بدقة متناهية.
  - **تخصيص التصاريح للطلب:** تخصيص التصاريح المتاحة للطلب آلياً أو يدوياً.
  - **إرسال التصاريح للعميل عبر الواتساب:**
    - زر فتح واتساب مباشر بنص معتمد ورسمي.
    - إمكانية مشاركة أو تنزيل صورة التصريح لإرسالها للمعتمر مباشرة.
  - **طباعة إيصال وفاتورة الطلب:** طباعة فورية احترافية تحمل شعار وبيانات المنشأة مع كود QR.

### د. إدارة العملاء (CRM & التسجيل الذاتي)
* **الوظائف:**
  - قاعدة بيانات كاملة للعملاء والمعتمرين مع أرقام الواتساب والهواتف الإضافية والملاحظات.
  - استيراد جماعي للعملاء عبر ملفات Excel أو نصوص الواتساب.
  - **بوابة التسجيل الذاتي للمعتمر:**
    - رابط مباشر يمكن إرساله للعميل: `/?register=true`
    - يقوم العميل بفتح الرابط من هاتفه وإدخال بياناته بنفسه، فتظهر فوراً في لوحة تحكم الموظفين دون أي تدخل يدوي.

### هـ. صندوق رسائل البنك ومطابقة السداد (SMS Inbox)
* **الوظائف:**
  - استقبال فوري لرسائل التحويلات البنكية الواردة لهاتف الشركة.
  - **المطابقة الذكية التلقائية:** مطابقة قيمة الحوالة البنكية الواردة برقم الطلب وتحديث حالة السداد إلى "مسدد" فوراً وتعديل رصيد الخزينة البنكية.

### و. الحسابات المالية والخزائن (Financial Accounts)
* **الوظائف:**
  - إدارة الحسابات البنكية والخزائن النقدية للشركة (الراجحي، الأهلي، كاش، إلخ).
  - متابعة الأرصدة الحالية، عمليات الإيداع، وحركات السداد المرتبطة بالطلبات.

### ز. إدارة الموظفين والأدوار والصلاحيات (Employees & Roles)
* **الوظائف:**
  - للمدير العام فقط (`super_admin`).
  - إضافة موظفين جدد بتحديد الاسم، اسم المستخدم، وكلمة المرور.
  - تخصيص الأدوار:
    - **مدير عام (Super Admin):** وصول كامل لكافة الشاشات وإدارة النظام.
    - **مبيعات (Sales):** شاشة الطلبات، العملاء، والتصاريح.
    - **مخزون وتصاريح (Inventory):** شاشة الفترات وإدارة ورفع التصاريح.
    - **محاسب (Accountant):** شاشة الحسابات المالية، رسائل البنك، والمبيعات.
  - التحكم الدقيق بالصلاحيات الفرعية: (عرض فقط / إنشاء / تعديل / حذف / تقارير).
  - إيقاف أو تنشيط أي موظف فوراً بنقرة زر.

### ح. إعدادات المنشأة والفواتير (Company Settings)
* **الوظائف:**
  - ضبط اسم المؤسسة بالعربي والإنجليزي، الشعار، أرقام الهواتف، والعنوان.
  - الرقم الضريبي والسجل التجاري وملاحظات تذييل الفاتورة.
  - اختيار العملة الافتراضية (ريال سعودي SAR، جنيه مصري EGP، دولار USD).

### ط. سجل العمليات والرقابة (Audit Logs)
* **الوظائف:**
  - تسجيل دقيق وغير قابل للتعديل لكل عملية تحدث في النظام (من أنشأ الطلب، من عدل السعر، من نقل تصريحاً، ومن سجل الدخول).
  - تصفية السجل حسب الموظف، التاريخ، أو نوع العملية، مع إمكانية التصدير إلى Excel.
