# Canvas Design Skill

This skill enforces a two-phase workflow for visual design:
1. **Design Philosophy (.md):** Define the artistic manifesto, visual world, mass vs negative space, typography as art, and color palette.
2. **Visual Expression:** Implement crisp, 90% visual / 10% typography graphics (SVG/HTML Canvas) with museum-grade aesthetics.
